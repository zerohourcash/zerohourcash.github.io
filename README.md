# zh.cash — облегчённая версия для GitHub Pages

Статический сайт из резервной копии от 04.09.2026. HTML/CSS/JS, русский и английский языки, видеофон, политика конфиденциальности и лицензия. Сборка и серверное приложение не нужны.

## Публикация

1. Создайте репозиторий GitHub, `zerohourcash/zerohourcash.github.io`.
2. Загрузите **содержимое этой папки** в корень ветки `main`: `index.html`, остальные HTML, `css`, `js`, `img`, `video`, `docs`, `download` и `.nojekyll`.
3. Откройте **Settings → Pages → Build and deployment**.
4. Выберите **Deploy from a branch**, ветку **main**, папку **/(root)** и нажмите **Save**.
5. После завершения публикации сайт будет доступен по адресу `https://zerohourcash.github.io/`.

Официальная инструкция: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Что облегчено

- Убраны старые версии, вложенные бэкапы, история Git, серверные скрипты, неиспользуемые библиотеки и дистрибутивы.
- Изображения оптимизированы в WebP; крупный SVG со встроенной картинкой заменён WebP.
- Видеофон: полный 30-секундный ролик, H.264, 1280×720, 24 кадра/с, без звука, с faststart. Автозапуск зависит от настроек браузера; при его блокировке остаётся постер.
- Используются системные шрифты и текстовые названия социальных сетей. Два внешних логотипа партнёров заменены их названиями; сайт не загружает визуальные ресурсы с чужих серверов.
- Исправлен порядок загрузки JavaScript и убрано повторное переопределение переводов.
- Относительные пути работают и в корне домена, и по адресу `/имя-репозитория/`.

## Документы и скачивания

Документация, включая RPC API и инструкции по кошелькам, доступна в `docs/en/` на самом сайте. White paper, руководство разработчика, PDF для валидаторов, брендбук и архив peers сохранены в `download/`. Ссылки не зависят от старого домена zh.cash. Дистрибутивы кошельков остаются в GitHub Releases.

Документы восстановлены из бэкапа от 04.09.2026 и помечены как архивные; актуальность команд для новых релизов отдельно не подтверждалась. Скриншоты сжаты в WebP без потери качества. Пять отсутствующих в бэкапе иллюстраций к salvagewallet явно обозначены; сторонние изображения Imgur по-прежнему зависят от внешнего сервиса.

Ссылки на старую базу знаний ведут в восстановленную документацию, а ссылки поддержки — в существующий Telegram-чат сообщества. Внешние сервисы с подтверждёнными ошибками DNS/521 отмечены как недоступные. Сбой этих сервисов нельзя устранить публикацией статического сайта. Ответы 403 от сторонних площадок не трактуются как закрытие сервиса.

Файл `CNAME` не задан: основной адрес — https://zerohourcash.github.io/.

Тексты и даты новостей сохранены из бэкапа; это не обновление содержимого сайта на текущую дату.

## Локальный просмотр

```sh
python3 -m http.server 8000
```

Откройте http://localhost:8000/.
